# Sec-Pulse

Personal cyber security news + CySA+ study PWA for a security analyst in Brisbane (Australian real-estate sector). Static files on GitHub Pages; no build step, no framework, no backend.

## Layout
- `index.html` - the whole app (inline CSS/JS). Tabs: Brief, News, Learn, Cards; Settings sheet.
- `data/news.json` - generated by `scripts/fetch_news.py` (GitHub Action, every 3h). Never hand-edit.
- `data/cysa.json` - hand-written study content: `domains`, `lessons` (each with a 3-question `quiz`), `cards`.
- `scripts/sources.json` - feed list + keyword groups used for relevance scoring.
- `scripts/send_brief.py` - morning brief via Web Push/ntfy, writes `data/brief.json` (`.github/workflows/morning-brief.yml`, 21:25 UTC = 7:25 AEST).
- `scripts/post_draft.py` - sends `blog/drafts/*.md` to WordPress.com as drafts (`.github/workflows/blog-drafts.yml`).
- `sw.js` - network-first service worker + Web Push handlers; bump `CACHE_NAME` when changing cache behaviour.
- `scripts/smoke-test.cjs` - headless Playwright check of the app (see context/testing.md).

## Conventions
- Python scripts are standard library only (no pip install in Actions). One exception: the brief/digest workflows `pip install pywebpush` for Web Push, imported lazily inside `send_webpush()` so the scripts still run (and `fetch_news.py` still imports `send_brief`) without it.
- One broken feed must never fail the run - errors are recorded in `news.json`'s `sources` health list.
- `rank()` (score minus age/12h) is duplicated in `index.html` and `send_brief.py`; the lesson-of-the-day pick (`ordinal % lessons`) and the question of the day (`(ordinal * 7) % questions`) are too. Keep them in sync.
- All dates are Australia/Brisbane (UTC+10, no daylight saving).
- localStorage keys are prefixed `sp_` (export/import/reset rely on that). Wrap storage access in try/catch.
- Quiz option order is shuffled at render time, so `answer` indexes can be anything in the JSON.
- The repo is public: keep keywords and content generic - never add employer-specific systems, vendors, domains or incident details.
- Study content must be accurate; Australian regulatory facts (NDB 30-day assessment, Cyber Security Act 2024 ransomware payment reporting within 72h for >$3M turnover) should be re-checked if edited.
